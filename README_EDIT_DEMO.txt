Ver.30.0 直接編集デモ（2026-10-09）

Ver.29 ZIPをベースに index.html / clinic.html のみ編集用スクリプトを追加。その他のページと画像は元ZIPから無変更で収録。

操作：GitHub PagesにZIPの中身をアップロード → /editor.html を開く → ページを選ぶ → 文章をタップして編集 → プレビュー → 下書き保存 → 変更を出力。

注意：この試作では公開・認証・サーバーへの保存は行いません。ブラウザのlocalStorageにのみ保存。公開されたページではクエリ ?edit=1 を知っている誰でもローカル編集デモを起動できますが、GitHub上のファイルは変更できません。
既存HTML構造を保護するため、編集対象は文章の一部のみです。見出しや複雑なHTMLは編集できません。写真編集は次フェーズ。
正式公開にあたっては、試作用編集スクリプトを公開サイトから分離し、管理者認証・安全な書込API・公開前承認・監査ログを設計してください。
