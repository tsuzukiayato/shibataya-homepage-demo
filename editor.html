03 / DIRECT EDIT

文章を直接編集する

Ver.30.0の文章タップ編集に加え、写真を直接タップして差し替えできます。各ページを開いたら文章をタップし、プレビューと下書き保存を試してください。

01 トップページを編集 →02 院長紹介を編集 →03 リハビリテーションの写真を編集 →04 物理療法の写真を編集 →05 運動療法の写真を編集 →06 栄養相談の写真を編集 →07 通所リハビリの写真を編集 →

写真は各ページの画像を直接タップして変更できます。変更はこの端末の下書きとしてページ上に表示されますが、公開サイトには反映されません。

04 / PUBLIC VIEW

現在のホームページを確認

編集ボタンのない既存ページを表示します。ここにはまだ写真の下書きは同じブラウザのプレビューにも表示されます。お知らせの下書きはまだ公開ページに反映されません。

05 / DRAFT DATA

下書きを持ち出す

写真とお知らせの下書きをJSONファイルとして保存・復元できます。Ver.30.0の各ページの文章下書きは別管理です。ファイルの読み込みはこの画面の下書きを上書きします。

重要：画像を含むJSONはサイズが大きくなることがあります。iPhoneのブラウザ保存領域が消去されると下書きが失われるため、適宜書き出して保管してください。公開機能・認証・複数端末同期は未実装です。
